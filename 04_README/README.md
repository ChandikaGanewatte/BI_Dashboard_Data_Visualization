# Global Superstore Sales & Profitability Dashboard

## Project Overview

This project develops an interactive Power BI dashboard for analyzing
Global Superstore sales and profitability data.

## Objectives

- Analyze overall sales and profit performance
- Identify high-performing categories and regions
- Analyze top-selling products
- Examine discount and profitability relationships
- Provide interactive filtering
- Implement drill-through product analysis

## Tools Used

- Power BI Desktop
- Power Query
- DAX
- CSV Dataset

## Dashboard Pages

### 1. Executive Overview
- KPI Cards
- Sales & Profit Trend
- Category Analysis
- Regional Profitability

### 2. Product Analysis
- Top 10 Products by Sales

### 3. Profitability Analysis
- Discount vs Profitability
- Product Performance Table

### 4. Product Details
- Drill-through analysis
- Product KPIs
- Yearly Sales and Profit

## Interactive Features

- Year slicer
- Category slicer
- Segment slicer
- Ship Mode slicer
- Region slicer
- Cross-page filtering
- Page navigation
- Product drill-through
- Reset Filters button

## Key Findings

- Technology is a strong contributor to sales and profit.
- Monthly sales show considerable variation.
- Several high-discount products generate negative profit.
- Some products generate high sales but relatively low profit margins.
- Product-level profitability should be considered alongside sales.
